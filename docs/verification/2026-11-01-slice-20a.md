## What each row claims, and the evidence that must appear

1. **Operator verdict cascade.** `metrics.AssessVerdict` is first-wins, the
   sealed report freezes `operator_verdict` and `load_attempted`, and no green
   is possible without a measured load.
   Evidence: `TestVerdictNeverGreenWithoutGrade`,
   `TestReportVerdictRefusesGreenWithoutLoad`. The verifier must follow one
   case by hand: `capSamples` collecting completions while `BulkLoad` failed
   still cannot produce `ok`.
2. **Remediation rates and assumed LAN interface.** Per-direction
   `up_shaped_mbps`/`down_shaped_mbps`, `routeros_lan_iface`, and
   `routeros_lan_assumed` — the assumed pair exists only where a RouterOS
   script exists.
   Evidence: `TestReportLinuxOnlyDownEmitsLinuxIngressAndNoRouterOS`. The
   `linux-only` case must carry no RouterOS block at all, not an empty one.
3. **Economics numbers per scenario.** `economics.*.numbers` carries model A's
   monthly charge and CIR, model B's and the emergency bound's Ar/GB, and no
   invented zero.
   Evidence: `TestBuildEconomicsNumbersPerModel`,
   `TestBuildEconomicsNumbersNotInventedWhenUnmeasured`,
   `TestEconomicsNumbersJSONKeys`.
4. **Campaign-frozen tier and the write guard.** `matrixConfig.tier` and
   `Deps.Tier` freeze one cost basis per run; `POST /api/cost/tier` answers 409
   while a campaign runs; a resumed run re-reads the frozen tier from
   `manifest.json`.
   Evidence: `TestMatrixConfigFreezesActiveTier`, `TestCostARPerHUsesFrozenTier`,
   `TestRunEventCostUsesFrozenTier`, `TestCostTierRefusedWhileCampaignRuns`,
   `TestResumeKeepsTheFrozenTier`. The verifier should confirm the guard tests
   the *running* flag, not merely the request body.
5. **Live per-second timeline.** `/api/audit/live` carries `timeline`, one
   bucket per elapsed second with the cap at `total_sec+5`, and a null value
   is never plotted as 0 ms.
   Evidence: `TestTimelineBucketsBySecondAndKeepsGaps`,
   `TestTimelineCapIsTotalPlusFive`, and the live test's contiguity assertion.
6. **Duel endpoint.** `GET /api/duel` picks the best cell and the `pfifo_fast`
   base in Go, requires `n ≥ 3`, cites only runs that fed a measurement, and
   breaks ties deterministically.
   Evidence: `go test ./pkg/api -run Duel -v`; `TestGroupRunsExcludeInvalidOnlyRuns`.
   The harness writes a throwaway corpus under `t.TempDir()` — confirm the run
   does not read `data/runs` by checking the test source, not by trusting this
   line.
7. **Run-start identifier.** `POST /api/run/start` validates `run_id` with the
   same `validRunID` every other run path uses, before the engine gate.
   Evidence: `../evade`, `..\evade`, `a/b`, `run.1` and `.` all answer 400 with
   `StartFn` never called.
